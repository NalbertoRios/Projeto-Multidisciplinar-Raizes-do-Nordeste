# Projeto Multidisciplinar Backend - Rede Raízes do Nordeste

## Stakeholders
| Stakeholder        | Papel/Interesse no Sistema |
|--------------------|-----------------------------|
| Professora         | Avaliação acadêmica e orientação técnica |
| Aluno              | Desenvolvimento e documentação do projeto |
| Franqueador        | Definição de regras, relatórios consolidados e expansão da rede |
| Franqueado         | Gestão da unidade local e integração com a matriz |
| Gerente da matriz  | Controle centralizado de vendas, estoque e fidelização |
| Gerentes regionais | Acompanhamento de desempenho por região |
| Funcionários       | Operação diária (atendentes, cozinheiros) |
| Clientes           | Consumo dos produtos e interação com múltiplos canais |
| Fornecedores       | Reposição de estoque e logística |
| Parceiros          | Integrações externas (pagamentos, campanhas) |

## Atores
| Ator              | Interação com o Sistema |
|-------------------|--------------------------|
| Cliente           | Realiza pedidos e acompanha status |
| Atendente         | Registra pedidos no balcão e atualiza status |
| Cozinheiro        | Recebe pedidos e sinaliza conclusão |
| Gerente local     | Controla estoque e acompanha desempenho da unidade |
| Gerente da matriz | Acessa relatórios consolidados e define promoções |
| Franqueado        | Supervisiona operação da unidade |
| Sistema de Pagamento (externo) | Recebe solicitações de pagamento e retorna status (mock) |

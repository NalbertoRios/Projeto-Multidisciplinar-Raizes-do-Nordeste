
# 14. Conclusão

O projeto **Rede Raízes do Nordeste** teve como objetivo desenvolver uma solução de backend para centralizar e gerenciar as operações de uma rede fictícia de franquias, contemplando pedidos, pagamentos, produtos, unidades, controle de estoque e programa de fidelidade.

Durante o desenvolvimento, foram aplicados conceitos e práticas de Análise e Desenvolvimento de Sistemas, incluindo:

- **Levantamento de requisitos e casos de uso:** identificação dos atores, funcionalidades e principais fluxos de negócio.
- **Modelagem de sistemas:** elaboração dos diagramas UML e do modelo de dados, considerando os relacionamentos e as regras de negócio.
- **Desenvolvimento da API:** implementação de serviços REST utilizando Python e FastAPI, com persistência de dados por meio do SQLAlchemy e SQLite.
- **Autenticação e controle de acesso:** utilização de JWT e permissões baseadas nos perfis dos usuários.
- **Regras de negócio:** implementação dos processos de pedidos, simulação de pagamentos, associação de produtos às unidades, controle de estoque e programa de fidelidade.
- **Proteção de dados:** inclusão de mecanismos relacionados ao registro e à revogação de consentimentos, considerando os princípios da Lei Geral de Proteção de Dados (LGPD).
- **Testes e validação:** realização de testes funcionais manuais e testes automatizados com Pytest.

O desenvolvimento permitiu integrar os conhecimentos teóricos e práticos adquiridos ao longo do curso, demonstrando a importância do planejamento, da modelagem, da organização arquitetural, da implementação e da documentação no ciclo de desenvolvimento de software.

Apesar dos resultados alcançados, o projeto apresenta possibilidades de evolução, como a ampliação da cobertura de testes automatizados, a integração com serviços externos de pagamento, o aprimoramento dos mecanismos de monitoramento e a expansão das funcionalidades administrativas.

Conclui-se que o projeto proporcionou uma experiência prática de desenvolvimento de backend, aplicando conceitos fundamentais de engenharia de software e demonstrando como uma API pode atender às necessidades operacionais de um sistema de gestão de franquias.
